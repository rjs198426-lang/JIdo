# 탭 전체 공통 디자인 · 0.90

탭마다 제목·탭·카드·동작이 달라 정돈된 앱으로 느껴지지 않는다는 피드백을 반영했다. 글자를 더 축소하지 않고 역할별 공통 크기와 화면 구조를 맞췄다.

## 검토·수정

- 모든 주요 화면: 같은 페이지 제목 크기와 시작점, 같은 테두리/모서리/입력/버튼/색상.
- 내 여행: 반복 관리 제목과 큰 아이콘 묶음을 제거하고 실제 여행명을 우선한다. 편집/삭제/백업/새 여행/전체 목록은 더보기에 모은다.
- 예약·경비: 페이지 제목 다음에 여행 문맥을 표시한다. 여러 여행 선택도 제목 아래에 둔다.
- 상위 작업은 선택형 메뉴, 하위 일정/준비/경비 보기는 같은 밑줄 메뉴로 구분한다. ‘가계부’는 화면에서 ‘경비’로 통일한다.
- 홈: 빈 준비물/자료는 가벼운 추가 행으로 표시하고 시간 미정이 세로로 꺾이지 않게 한다.
- 여행 중: 메모 중복을 없애고 개인 사진이 없는 큰 빈 영역을 축소한다. 개인 사진 원본/표시는 보존한다.
- 예약: 항공/호텔/기타 추가를 한 행으로 묶는다. 설정: 공통 그룹 목록과 짧은 안내로 정리한다.

## 검증 범위

320/393/768/1440px의 가로 넘침·실제44px 메뉴·페이지 제목 위계·한 화면의 예약 번호·더보기의 Escape/바깥 터치/초점 복귀·여러 여행 선택·조회 중 원문 보존을 확인한다. 전체292개 통과 후 정산/통계/예산의 반복 요약과 호텔 입력 화면을 추가 보완해 관련 검사를 다시 실행했다. 새 검사는 각 기능/입력이 첫 화면에서 보이는지와 취소 시 원문 보존을 확인한다. 마지막 수정에 관련된130개도 최종 파일로 통과했다. 서로 다른 검사 수는 새2개를 포함한294개이며 중복 합산하지 않았다. Android 빌드/서명/웹 자산 일치와 공개 파일 확인 결과는 [배포 기록](../../release-0.90-verification.json)에 기록한다.

실제 Android 설치·제조사 키보드/갤러리·TalkBack·Google 로그인/휴대폰 두 대 동기화는 미검증이다. 브라우저의 두 기기 동기화 검사는 모형 서버와 독립 문맥을 사용한다.
