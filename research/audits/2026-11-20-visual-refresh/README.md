# 0.91 화면 비교

홈은 여행명, 출발까지 남은 날, 기간, 일정 열기를 하나의 카드에 담았다. 경비의 지출 화면은 총액과 사용 가능한 예산 정보를 같은 색상 체계로 보여 준다. 일정·예약·설정·입력창에는 밝은 녹색 바탕, 같은 모서리와 테두리, 구분되는 버튼을 적용했다. 홈 바로가기 아이콘을 일정한 크기로 맞추고 현재 하단 메뉴를 보조 기술에 알린다.

393×850 브라우저에서 같은 예시 여행을 비교했다. 개인 자료를 사용하지 않았다.
