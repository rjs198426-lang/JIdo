# 화면 밀도·정렬 비교 · 0.89

393×850 브라우저의 동일한 합성 괌4일 여행, 일정1곳, 항공 예약1건을0.88과 비교했다. 개인 자료는 사용하지 않았고 외부 응답은 차단했다. 문서 전체 높이를 측정했으며 여행의 기록량에 따라 실제 스크롤 길이는 달라진다.

첫 일정 카드 시작점은 599.7px에서 532.4px로 67.3px 올라왔다. 홈 예약 번호가 첫 화면의 하단 메뉴 위에 보이는지, 제목/카드 정렬, 본문 안 추가 버튼의 실제44px 크기,320/393/768/1440px 가로 넘침, 조회 후 저장 원문 보존을 검사한다.
