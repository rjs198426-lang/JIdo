## 검증 계약

새22개 검사는 날짜 미정 장소 보관→원하는 날짜에 담기, 저장 실패·재시도, 수정·삭제와 기존 일정 독립, 과거 장소 재사용/중복 방지, 예약·경비 진입/재실행, 복합 예약 검색, 전체 일정·시간 미정·별도 예약, 도시/국가/시간대,65개 목록의 페이지 표시와 전체 검색, 기존 백업·Drive 형식과 시계 결과를 다룹니다.

기존 경비·정산·환불·저장 장애·자료 복구·사진·첨부·Drive 충돌·알림·지도 모형 검사를 포함해 최종 결과를 기록합니다. 브라우저의 외부 요청은 차단하거나 모형으로 처리하며 실제 무료 검색/Google 경로 서비스·Android 설치·OAuth 로그인·두 휴대폰 동기화와 구분합니다.

시계 비교는5개 시간대·500회에 대해 기존Intl 출력과 동일함을 검사하며 별도의500회 포맷 생성/재사용 시간을 부가 기록합니다. 실행 환경의 영향을 받는 부분 측정이므로 앱 전체 실행속도나 배터리 개선율로 해석하지 않습니다.
