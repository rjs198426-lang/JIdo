# 장소 분류 보강 — 2026-10-18 (한국 시간)

관광 765/900곳에 편중되어 있던 목록에 관광 외 장소 166곳을 추가하고 기존 66곳의 분류를 수정했다. 전체는 21개 여행지·1,066곳이다. 모든 여행지에 관광·맛집·카페·숙소·바·공연·쇼핑·체험이 있고 맛집·카페·숙소는 각각 최소 2곳이다.

신규 166곳은 Wikivoyage 개별 항목·쇼핑 본문 163곳과 실제 개인 방문 후기 본문 2편의 카페 3곳에 근거한다. 도시·장소·지점·주소와 항목 설명을 읽고 선정했다. 동일 장소로 확인된 21개 후보는 기존 ID를 유지하고 중복으로 추가하지 않았다. 시장·쇼핑몰·서점은 쇼핑, 온천·스포츠·영화·놀이시설은 체험, 극장은 바·공연으로 주된 이용 목적에 따라 정리했다. 해변·사찰·일반 공원을 숫자만 맞추기 위해 체험으로 옮기지 않았다. 지도·박물관·야생동물 시설의 방문 방식에 따라 일부는 관광으로 유지한다.

- `src/balanced-places.json`: 신규 장소와 한국어 요약, 원어, 실제 확인한 출처.
- `src/place-category-updates.json`: 기존 ID·도시·기본 이름·이전 분류가 모두 일치할 때만 적용하는 분류 변경.
- `public/category-place-research.json`: 신규 장소별 고정 revision·원문 listing·좌표 근거, 블로그 본문 길이·해시·검사 기록, 중복·제외 기록. 블로그 본문·사진은 복제하지 않는다.
- `coverage.json`: `node --experimental-strip-types scripts/audit-place-categories.mjs --output research/categories/coverage.json`으로 생성하는 여행지별 분류 개수.

원문 자료 확인은 현재 영업·요금·입장 조건·공연 회차·숙박 가능 여부의 검증이 아니다. 원문에 없는 최신 가격·영업시간·대기·평점은 만들지 않았다. 좌표가 있는 listing만 원문 좌표를 사용하며, 정확한 좌표 쌍이 없는 곳은 지도 핀을 생략한다. 지역명이나 도시 중심으로 좌표를 채우지 않는다. 현재 명칭·영업의 추가 확인이 필요한 숙소 구명칭과 특정 장소로 식별할 수 없는 체인·투어 판매·계절 행사 등은 제외했다.

‘전체’에서는 분류를 순환해 첫 목록에도 여러 선택지를 보여준다. 분류 안에서는 기존 순서를 유지하며 검색·도시 선택·개별 분류 필터는 오프라인으로 동작한다. 원문을 여는 경우만 외부 연결이 필요하다. 저장한 일정 원본·사용자가 변경한 분류·이름·메모·사진은 덮어쓰지 않고, 쇼핑·체험·바·공연은 새 일정과 백업에서도 같은 이름으로 보존한다. 가이드 스키마와 개인 장소 스키마의 분류 목록을 함께 관리한다.

신규 사진을 확보한 작업은 아니다. 기존 유효 사진 70곳과 개인 사진 우선순위를 유지하며 누락은 996곳이다. `research/photos/coverage.json` 및 `missing-photos.csv`에 신규 장소를 반영했다. 타 장소의 사진이나 생성 사진으로 빈 사진을 채우지 않았다. Wikivoyage 원문과 한국어 요약·분류 편집에는 기존 CC BY-SA 4.0 출처·이용 조건을 유지한다.
