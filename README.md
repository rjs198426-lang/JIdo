# J★Do · 나와 동행자의 해외여행 도구

여행을 계획하고, 현장에서 일정과 예약을 확인하고, 사용한 돈과 동행자 정산을 관리하는 Android 앱입니다.

[0.84 개발판 APK 다운로드·업데이트 안내](ANDROID-DOWNLOAD.md) · [개편 내용과 자료 보존](TRAVEL-WORKSPACE.md)

- **홈:** 가까운 날짜의 일정, 항공·호텔 예약, 준비물과 경비 현황
- **내 여행:** 직접 정한 날짜별 일정, 여행·장소 사진과 대표 선택, 여러 도시, 지도·동선·이동시간, 여행 중 완료·메모·첨부·길찾기
- **예약:** 항공사·편명·공항·현지 출발/도착 시각, 호텔 체크인/체크아웃·연락처·예약 번호·확인 링크·비용·파일
- **경비:** 통화별 지출·환불·예산·환율·통계, 동행자 분담·정산·송금 기록, CSV
- **설정:** 알림, 전체 백업·복원, 선택한 Google Drive 동기화, 기존 사진 출처

가이드·추천 장소·블로그·코스·가이드북 다운로드는 제공하지 않습니다. 도시·국가·날짜로 여행을 만들고 일정은 직접 입력하거나 지도에서 찾아 담습니다. 기존 일정에 사용한 장소·사진·메모·예약·경비는 보존합니다.

시간은 나중에 정해도 됩니다. 예약은 이미 예약한 내역을 기록하며, 실제 예약이나 실시간 항공 정보 조회·은행 송금을 실행하지 않습니다. 예약의 일정 연결과 비용 기록은 사용자가 선택할 때만 진행합니다.

기본 저장은 이 기기입니다. 기기 변경 전에 전체 ZIP 백업을 보관하고, 여러 기기는 같은 Google 계정의 Drive를 선택적으로 연결하세요. 새 항공·호텔 상세를 동기화할 모든 기기는0.83 이상이 필요합니다. 기존 앱은 삭제하지 말고 업데이트합니다.

내 사진은 홈/내 여행의 **여행 사진** 또는 일정 카드의 **사진**에서 추가합니다. 사진을 포함하려면 전체ZIP 백업을 사용하세요. [사진 사용과 보존](PERSONAL-TRAVEL-PHOTOS.md).

```sh
npm ci
npm run build
npm test
```
